# Name clearance notes (BL-003)

The nearest names in the same space are different words: Cinephage, Cantinarr, Reiverr, Jellyseerr and MediaManager.

This is a quick search, not a legal clearance. Before a public release the owner should still check, with the real services and not through a search engine:

- trademark registers in the countries that matter (New Zealand IPONZ, US USPTO, EU EUIPO, WIPO) for software classes 9 and 42;
- GitHub, Docker Hub, GHCR, npm and NuGet names;
- domain names and social handles;
- whether "-arr" in the name suggests a link with the Sonarr or Radarr projects (the README says there is none).
